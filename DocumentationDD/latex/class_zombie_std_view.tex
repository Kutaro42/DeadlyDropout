\doxysubsection{Detailed Description}
Graphics component (View) of the standard zombie. 


\begin{DoxyItemize}
\item Inherits from QGraphics\+Pixmap\+Item for Qt rendering. Manages walk and idle animations based on the AI state (Idle/\+\+Chasing). 
\end{DoxyItemize}
