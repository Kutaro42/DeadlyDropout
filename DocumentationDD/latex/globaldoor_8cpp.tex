\doxysubsection{Detailed Description}
Implementation of the \doxylink{class_global_door}{Global\+Door} base class. 

The constructor simply forwards position and dimensions to \doxylink{class_entity}{Entity}. All door-\/specific logic (open/\+close state, teleportation, key checking) lives in the concrete subclasses so that this file stays minimal and the inheritance chain remains easy to extend.
