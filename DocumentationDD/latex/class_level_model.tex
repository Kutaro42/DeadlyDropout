\doxysubsection{Detailed Description}
Conteneur de données pour les entités d\textquotesingle{}un niveau. 


\begin{DoxyItemize}
\item Stocke les murs, les ennemis, la porte de sortie et les positions initiales. Ce modèle est peuplé par le \doxylink{class_level_builder}{Level\+Builder} au moment du chargement de la carte.
\item \begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}

\end{DoxyItemize}
