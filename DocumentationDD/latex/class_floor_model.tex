\doxysubsection{Detailed Description}
Entité statique décorative représentant une tile de sol. 

Contrairement à \doxylink{class_wall_model}{Wall\+Model}, \doxylink{class_floor_model}{Floor\+Model} n\textquotesingle{}a aucun rôle dans la résolution des collisions :\+ il est uniquement utilisé par \doxylink{class_floor_view}{Floor\+View} pour l\textquotesingle{}affichage. Son collider est présent (hérité d\textquotesingle{}\doxylink{class_entity}{Entity}) mais n\textquotesingle{}est jamais consulté par le \doxylink{class_level_controller}{Level\+Controller}.
