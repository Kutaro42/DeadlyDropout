\doxysubsection{Detailed Description}
Modal dialog presenting the upgrade shop between levels (GDD Step 5). 

The view is kept intentionally dumb:\+ it displays item names, costs and descriptions, disables buttons the player cannot afford, and emits sig\+Buy when a button is clicked. All balance values and stat changes live in \doxylink{class_market_controller}{Market\+Controller}, not here, so the GDD balancing can be adjusted without touching the UI code.

ITEMS is a static table so it can be shared between \doxylink{class_market_view}{Market\+View} (display) and \doxylink{class_market_controller}{Market\+Controller} (cost lookup) without duplicating data.
