\doxysubsection{Detailed Description}
Orchestrator of the in-\/game MVC loop. 

Responsibilities (single-\/responsibility breakdown):\+
\begin{DoxyItemize}
\item Creates and links \doxylink{class_game_model}{Game\+Model}, \doxylink{class_game_view}{Game\+View} and \doxylink{class_level_controller}{Level\+Controller}.
\item Loads a level via \doxylink{class_level_builder}{Level\+Builder} using descriptors from \doxylink{class_level_registry}{Level\+Registry}.
\item Reads keyboard/\+mouse input from \doxylink{class_game_view}{Game\+View} on every tick.
\item Delegates physics and AI to \doxylink{class_level_controller_aae80ed7c5005afa9ed3c1f9b4ce7db00}{Level\+Controller::\+update()}.
\item Detects state transitions (PLAYING → GAME\+\_\+\+OVER /\+ VICTORY /\+ MARKET).
\item Opens \doxylink{class_market_controller}{Market\+Controller} between levels without exposing it to the view.
\end{DoxyItemize}

The QTimer drives the game loop at \texorpdfstring{$\sim$}{\string~}60 FPS (\doxylink{namespace_cfg_a66f5c4418edf282f2c5800098d222412}{Cfg::\+\+TIMER\+\_\+\+MS}). QElapsed\+Timer measures real elapsed milliseconds so that dt is accurate even if a tick fires slightly late (avoids physics drift on slow machines).
