\doxysubsection{Detailed Description}
Affiche un mur en découpant la bonne tile depuis le tileset. 

Le tileset doit être chargé une seule fois (cache statique). La tile est sélectionnée via l\textquotesingle{}index stocké dans \doxylink{class_wall_model}{Wall\+Model} :\+ col = (index -\/ 1) \% tileset\+Cols row = (index -\/ 1) /\+ tileset\+Cols
