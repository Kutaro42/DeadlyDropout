\doxysubsection{Detailed Description}
Root model aggregating persistent game-\/session data (MVC Model layer). 

Owns exactly one \doxylink{class_player_model}{Player\+Model} and one \doxylink{class_level_model}{Level\+Model} at any time. It does NOT own game logic — that responsibility belongs to \doxylink{class_game_controller}{Game\+Controller} and \doxylink{class_level_controller}{Level\+Controller}. Keeping data and logic separate means the model can be serialised, reset or inspected by tests without running the game loop.

The boss pointer is kept here (rather than only in \doxylink{class_level_model}{Level\+Model}) so that \doxylink{class_game_controller}{Game\+Controller} can query boss state for music/\+\+UI purposes without having to search the enemy list every frame.
