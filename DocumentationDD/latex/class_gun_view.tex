\doxysubsection{Detailed Description}
Graphics item for the pistol:\+ anchored on the player and rotated toward the cursor. 

Positioning strategy:\+
\begin{DoxyItemize}
\item The rotation pivot is set to the LEFT edge of the sprite (anchor point on the player).
\item set\+Rotation(deg) rotates the sprite around that pivot → no positional drift.
\item When the cursor is to the left of the player, the sprite is pre-\/flipped vertically via a mirrored QPixmap (NOT via set\+Transform) to avoid conflicting with set\+Rotation.
\end{DoxyItemize}

Sprite loading order (first non-\/null wins):\+
\begin{DoxyEnumerate}
\item :\+/\+images/\+\+Textures/\+\+Player/\+\+Gun/\+gun.png
\item :\+/\+images/\+\+Textures/\+\+Player/\+gun.png
\item Procedural fallback (dark-\/grey body + barrel, GUN\+\_\+W × GUN\+\_\+H).
\end{DoxyEnumerate}

Expected PNG convention:\+ barrel pointing RIGHT (angle 0°), transparent background, any source dimensions (scaled to GUN\+\_\+W × GUN\+\_\+H at runtime).

Bullet management:\+ A \doxylink{class_bullet_view}{Bullet\+View} is created for each new \doxylink{class_bullet_model}{Bullet\+Model} and removed from the scene as soon as the model becomes inactive, keeping scene items in sync with the model.
