\doxysubsection{Detailed Description}
Controller for the BDE Market upgrade shop (GDD Step 5 — Market rules). 

The market is a modal interaction:\+ the game loop is stopped, the player buys upgrades, then the loop resumes. Using QDialog::\+exec() inside \doxylink{class_market_controller_af72fd62631683d7f0eee5172acb20bf0}{open()} achieves this without a separate application state, keeping \doxylink{class_game_controller}{Game\+Controller}\textquotesingle{}s state machine simpler.

All upgrade bonus values are defined as named constants below so that balancing changes require edits in one place rather than scattered magic numbers.
