\doxysubsection{Detailed Description}
Controller responsible for handling interactions on the welcome screen. 

Sits between \doxylink{class_menu_view}{Menu\+View} and \doxylink{class_app_controller}{App\+Controller} in the MVC chain. Its only job is to relay the "{}\+Play"{} click upward as sig\+Game\+Request so that \doxylink{class_app_controller}{App\+Controller} — not the view — owns the decision to switch application state. Keeping this relay in a dedicated controller means the view can be replaced (e.\+g. a full-\/screen animated intro) without changing \doxylink{class_app_controller}{App\+Controller}.
