int main (\begin{DoxyParamCaption}\item[{int}]{argc}{, }\item[{char \texorpdfstring{$\ast$}{*}}]{argv}{\+[$\,$]\+}\end{DoxyParamCaption})}



Main function of the program. 

Creates the Qt application, instantiates the top-\/level controller (\doxylink{class_app_controller}{App\+Controller}) and starts the Qt event loop.

\doxylink{class_app_controller}{App\+Controller} is used rather than directly instantiating \doxylink{class_game_controller}{Game\+Controller} or \doxylink{class_menu_controller}{Menu\+Controller} so that the application-\/level state machine (MENU → PLAYING → GAME\+\_\+\+OVER …) lives in one place and neither the menu nor the game need to know about each other.
