\doxysubsection{Detailed Description}
Item graphique représentant une tile de sol. 

Fonctionne exactement comme \doxylink{class_wall_view}{Wall\+View} :\+ le tileset est chargé une seule fois via un cache statique, puis la tile est découpée selon l\textquotesingle{}index stocké dans le \doxylink{class_floor_model}{Floor\+Model} associé.

La tile est placée sur la couche Z\+\_\+\+FLOOR, sous les murs et les entités.

Formule de découpe (identique à \doxylink{class_wall_view}{Wall\+View}) :\+ col = (tile\+Index -\/ 1) \% tileset\+Cols row = (tile\+Index -\/ 1) /\+ tileset\+Cols
