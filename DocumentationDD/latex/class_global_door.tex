\doxysubsection{Detailed Description}
Base entity from which standard doors, boss doors and level-\/exit zones inherit. 

The GDD (Step 5 — \doxylink{class_entity}{Entity} rules) defines three distinct door behaviours:\+
\begin{DoxyItemize}
\item Standard door :\+ blocks passage, opened by player interaction.
\item Boss door :\+ teleports the player and locks behind them.
\item Level-\/exit zone:\+ detects the player + key and triggers the next level.
\end{DoxyItemize}

Rather than duplicating position/\+collision data in each subclass, \doxylink{class_global_door}{Global\+Door} inherits \doxylink{class_entity}{Entity} and acts as a single structural anchor. Behaviour differences are implemented in the subclasses so that \doxylink{class_level_controller}{Level\+Controller} can treat all doors polymorphically when iterating the entity list.
