Detailed Description

Entité statique décorative représentant une tile de sol.

Contrairement à WallModel, FloorModel n'a aucun rôle dans la résolution des collisions : il est uniquement utilisé par FloorView pour l'affichage. Son collider est présent (hérité d'Entity) mais n'est jamais consulté par le LevelController.
