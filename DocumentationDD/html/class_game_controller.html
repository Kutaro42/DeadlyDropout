Detailed Description

Orchestrator of the in-game MVC loop.

Responsibilities (single-responsibility breakdown):

  • Creates and links GameModel, GameView and LevelController.
  • Loads a level via LevelBuilder using descriptors from LevelRegistry.
  • Reads keyboard/mouse input from GameView on every tick.
  • Delegates physics and AI to LevelController::update().
  • Detects state transitions (PLAYING → GAME_OVER / VICTORY / MARKET).
  • Opens MarketController between levels without exposing it to the view.

The QTimer drives the game loop at ~60 FPS (Cfg::TIMER_MS). QElapsedTimer measures real elapsed milliseconds so that dt is accurate even if a tick fires slightly late (avoids physics drift on slow machines).

void GameController::loadLevel ( int index)

Loads and initialises a level by index using LevelRegistry.

Clears the current scene, asks LevelBuilder to populate model + scene, then repositions the player at the new spawn point. LevelRegistry::init() MUST be called before the first loadLevel() call to avoid a modulo-by-zero crash.

Parameters
