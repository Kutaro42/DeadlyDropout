int main ( int argc,

Main function of the program.

Creates the Qt application, instantiates the top-level controller (AppController) and starts the Qt event loop.

AppController is used rather than directly instantiating GameController or MenuController so that the application-level state machine (MENU → PLAYING → GAME_OVER …) lives in one place and neither the menu nor the game need to know about each other.
