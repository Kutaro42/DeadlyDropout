Detailed Description

Vue non-propriétaire sur les trois matrices d'un niveau.

Les pointeurs entityData, wallData et floorData NE POSSÈDENT PAS les données : leur durée de vie est gérée par l'appelant (buffer statique constexpr ou DynamicLevelDescriptor).
