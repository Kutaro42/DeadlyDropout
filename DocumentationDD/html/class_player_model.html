Detailed Description

Model encapsulating the player's properties, resources and actions.

Manages HP, speed, gold, keys and cardinal orientation. Katana actions are delegated to the internal instance.

The cardinal orientation (facingDir) is determined either by keyboard movement or by the attack angle passed to launchKatana(). Priority rule: if the player is attacking, the cardinal direction is the one closest to the attack angle; otherwise it follows the keyboard.

◆ launchKatana()

bool PlayerModel::launchKatana ( float angleRad)

Launches a katana attack aimed at a free angle.

Converts the angle into the dominant cardinal direction to pick the correct sprite, then delegates to Katana::tryAttack() with the exact angle so that the SlashZone is oriented precisely toward the cursor.

Parameters
angleRadAngle in radians (standard atan2: 0=right, π/2=down).
Returns
true if the attack was triggered, false if the katana is on cooldown.
