Detailed Description

View responsible for rendering and handling clicks on the main screen.

Kept intentionally thin: it owns no business logic and emits a signal when the player clicks "Play", delegating the decision of what to do next entirely to MenuController. This separation means the visual layout can be redesigned without touching any game-state code.

Renders the background image, the game logo and the Play/Quit buttons.

void MenuView::paintEvent ( QPaintEvent * event)

Qt paint-event override used to draw the background and logo.

Drawing is done here rather than with QLabel pixmaps so that the logo and background can be precisely composited at the exact pixel positions defined by the GDD wireframe.
