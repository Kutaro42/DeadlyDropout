Detailed Description

Base entity from which standard doors, boss doors and level-exit zones inherit.

The GDD (Step 5 — Entity rules) defines three distinct door behaviours:

  • Standard door : blocks passage, opened by player interaction.
  • Boss door : teleports the player and locks behind them.
  • Level-exit zone: detects the player + key and triggers the next level.

Rather than duplicating position/collision data in each subclass, GlobalDoor inherits Entity and acts as a single structural anchor. Behaviour differences are implemented in the subclasses so that LevelController can treat all doors polymorphically when iterating the entity list.
