Detailed Description

Modal dialog presenting the upgrade shop between levels (GDD Step 5).

The view is kept intentionally dumb: it displays item names, costs and descriptions, disables buttons the player cannot afford, and emits sigBuy when a button is clicked. All balance values and stat changes live in MarketController, not here, so the GDD balancing can be adjusted without touching the UI code.

ITEMS is a static table so it can be shared between MarketView (display) and MarketController (cost lookup) without duplicating data.
