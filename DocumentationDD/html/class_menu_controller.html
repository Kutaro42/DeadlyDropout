Detailed Description

Controller responsible for handling interactions on the welcome screen.

Sits between MenuView and AppController in the MVC chain. Its only job is to relay the "Play" click upward as sigGameRequest so that AppController — not the view — owns the decision to switch application state. Keeping this relay in a dedicated controller means the view can be replaced (e.g. a full-screen animated intro) without changing AppController.
