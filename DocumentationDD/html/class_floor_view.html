Detailed Description

Item graphique représentant une tile de sol.

Fonctionne exactement comme WallView : le tileset est chargé une seule fois via un cache statique, puis la tile est découpée selon l'index stocké dans le FloorModel associé.

La tile est placée sur la couche Z_FLOOR, sous les murs et les entités.

Formule de découpe (identique à WallView) : col = (tileIndex - 1) % tilesetCols row = (tileIndex - 1) / tilesetCols
