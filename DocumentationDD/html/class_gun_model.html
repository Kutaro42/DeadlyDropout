Detailed Description

Manages firing logic, magazine, ammo reserve and shoot cooldown (GDD Step 5).

GDD ammunition rules:

  • Semi-auto: 1 click = 1 shot, 0.5 s cooldown between shots.
  • Magazine (mag) + general reserve (reserve).
  • Press R to reload: fills the magazine from reserve, preserving existing rounds.
  • Damage: 12 base + random 2–5 bonus + 2 % critical chance × 2 multiplier.
  • Bullet speed: 500 px/s.

BulletModel instances are owned by GunModel and updated every tick. LevelController accesses getBullets() to resolve collision with enemies.

Sound effects are allocated here rather than in the view because the trigger condition (successful shot / empty mag) is a model-level event, and playing audio in the view would require it to poll the model state every frame.

void GunModel::reload ( )

Reloads the magazine from the general reserve (GDD ammo rules).

Preserves rounds already in the mag and only transfers what is needed to fill it, so the player does not waste ammo by reloading mid-magazine.

Attempts to fire one bullet if the cooldown has elapsed and the mag is non-empty.

Returns false (and plays an empty-mag click) when no shot can be fired. This pattern avoids exposing internal timer state to callers.

Parameters
