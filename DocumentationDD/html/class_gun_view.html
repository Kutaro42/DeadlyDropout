Detailed Description

Graphics item for the pistol: anchored on the player and rotated toward the cursor.

Positioning strategy:

  • The rotation pivot is set to the LEFT edge of the sprite (anchor point on the player).
  • setRotation(deg) rotates the sprite around that pivot → no positional drift.
  • When the cursor is to the left of the player, the sprite is pre-flipped vertically via a mirrored QPixmap (NOT via setTransform) to avoid conflicting with setRotation.

Sprite loading order (first non-null wins):

  1. :/images/Textures/Player/Gun/gun.png
  2. :/images/Textures/Player/gun.png
  3. Procedural fallback (dark-grey body + barrel, GUN_W × GUN_H).

Expected PNG convention: barrel pointing RIGHT (angle 0°), transparent background, any source dimensions (scaled to GUN_W × GUN_H at runtime).

Bullet management: A BulletView is created for each new BulletModel and removed from the scene as soon as the model becomes inactive, keeping scene items in sync with the model.

void GunView::syncBulletViews ( QGraphicsScene * scene)

Keeps bulletViews in sync with the gun model's active bullet list.

Creates new BulletView entries for newly spawned bullets and removes entries for bullets that have become inactive (hit a wall or enemy). Runs in O(n) per tick where n = number of active bullets.

Parameters
sceneQt scene for item insertion/removal.

Updates gun position/rotation and synchronises bullet views.

Called once per game-loop tick by GameView::updateAllViews(). The cursor position must be in scene coordinates (not widget coordinates) so that the aim direction is correct regardless of camera scroll.
