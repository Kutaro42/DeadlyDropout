Detailed Description

Controller for the BDE Market upgrade shop (GDD Step 5 — Market rules).

The market is a modal interaction: the game loop is stopped, the player buys upgrades, then the loop resumes. Using QDialog::exec() inside open() achieves this without a separate application state, keeping GameController's state machine simpler.

All upgrade bonus values are defined as named constants below so that balancing changes require edits in one place rather than scattered magic numbers.

◆ open()

void MarketController::open ( PlayerModel * player)

Opens the market modal and blocks until the player clicks "Continue".

GameController calls this between levels after stopping the game timer. The blocking nature means the caller does not need an async callback — execution simply resumes after the player is done shopping.

Parameters
