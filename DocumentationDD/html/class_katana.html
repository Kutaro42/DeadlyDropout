Detailed Description

Model of the player's melee weapon (GDD Step 5 — Combat rules).

Manages weapon statistics (damage, range), its collision zone (SlashZone), and timers for cooldown and animation.

Design decision — free-angle slash: The SlashZone is computed from an arbitrary angle (radians) passed to tryAttack(). This allows attacking in any direction (not just the 4 cardinals), matching the GDD requirement that the katana targets "enemies within the player's range zone" oriented toward the mouse cursor.

The AABB returned by getSlashZone() is the bounding box of the oriented slash rectangle, ensuring compatibility with the existing AABB collision tests in LevelController without requiring a full OBB intersection algorithm.

The attack angle is exposed via getAttackAngle() so PlayerView can orient the slash sprite effect correctly.

float angleRad )

Computes the AABB enclosing the oriented slash rectangle for a given angle.

The logical slash rectangle has dimensions KATANA_SLASH_W × itsRange. Its near edge starts at the player's hitbox boundary (not at the centre) to avoid hitting enemies directly behind the player. The four corners are rotated by angleRad and their axis-aligned bounding box is computed to produce the final AABB.

Parameters
playerPosTop-left corner of the player's hitbox.
playerWHitbox width.
playerHHitbox height.
angleRadAttack direction in radians.

QRectF Katana::getSlashZone ( ) const

Returns the AABB bounding box of the oriented slash rectangle.

Used by LevelController for AABB-based collision tests with enemies. The AABB over-approximates the true oriented rectangle, which can cause false positives at extreme angles; acceptable for a game with 64 px entities.

Attempts to launch an attack in the direction given by an angle.

Fails silently (returns false) if the weapon is still on cooldown, so the caller does not need to query isReady() separately.

Parameters

playerWHitbox width in pixels.

angleRadAttack direction in radians (atan2 standard: 0 = right, π/2 = down).
Returns
true if the attack was launched (cooldown was ready), false otherwise.
