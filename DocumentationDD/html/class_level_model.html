Detailed Description

Conteneur de données pour les entités d'un niveau.

  • Stocke les murs, les ennemis, la porte de sortie et les positions initiales. Ce modèle est peuplé par le LevelBuilder au moment du chargement de la carte.
  • Version
    1.0
