Note
Ce fichier ne contient PLUS les données de niveaux (matrices inline). Les matrices sont désormais stockées dans des fichiers texte :

levels/ level_1/ entities.txt walls.txt floor.txt level_2/ entities.txt walls.txt floor.txt ...

Pour charger un niveau, utilisez MatrixExtractor::load() (voir matrixextractor.h), puis passez le DynamicLevelDescriptor::asDescriptor() à LevelBuilder::build().

Pour enregistrer la liste complète des niveaux, voir levelregistry.h.
