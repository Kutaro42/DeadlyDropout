Detailed Description

Affiche un mur en découpant la bonne tile depuis le tileset.

Le tileset doit être chargé une seule fois (cache statique). La tile est sélectionnée via l'index stocké dans WallModel : col = (index - 1) % tilesetCols row = (index - 1) / tilesetCols
